# Nutty Inc / OneOS

This repository hosts **OneOS**, a minimal root-based Linux distro image designed for Windows Subsystem for Linux (WSL).

## Quick start
- Read `oneos/README.md` for build and import instructions.
- Run `sudo bash oneos/build-oneos.sh` on a Debian/Ubuntu host (or fetch with `curl -fsSL <raw-url> | sudo bash`) to generate the OneOS rootfs tarball.
