Operate and maintain

Keep OneOS healthy after import.

Update cadence

Inside WSL, update with sudo apt update && sudo apt upgrade. Rebuild and re-import periodically for a fresh base.

If you maintain multiple instances, keep a small changelog of package adds so you can replay them after a rebuild.

Troubleshooting

Common fixes:

  • Missing network tools? Add them via ONEOS_PACKAGES and rebuild.
  • Slow mirror? Point ONEOS_MIRROR to a closer Debian endpoint.
  • WSL import issues? Ensure the path to oneos.tar.gz is on the Windows filesystem, not under \\wsl$.
