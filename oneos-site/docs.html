Start here

Build a OneOS tarball.

Use a Debian/Ubuntu host with debootstrap available. The script handles the rest.

Steps
  1. Install prerequisites: sudo apt update && sudo apt install -y debootstrap xz-utils.
  2. Run the script: sudo bash oneos/build-oneos.sh.
  3. Locate the tarball (defaults to oneos.tar.gz in the repo root).
  4. Transfer it to a Windows path (e.g., C:\\OneOS).
  5. Import into WSL: wsl --import OneOS C:\\OneOS oneos.tar.gz --version 2.

See oneos/README.md for the full build guide.

Tune the build

Environment variables you can set.

Control mirrors, release, and package footprint without editing the script.

  • ONEOS_RELEASE – Debian suite (e.g., bookworm).
  • ONEOS_MIRROR – Choose a nearby Debian mirror.
  • ONEOS_PACKAGES – Additional packages installed during bootstrap.
  • ONEOS_TARBALL – Name for the exported archive.

All variables are documented in oneos/README.md.

Example: dev-ready build
ONEOS_RELEASE=bookworm \
ONEOS_PACKAGES="git ca-certificates curl" \
ONEOS_MIRROR=https://deb.debian.org/debian \
sudo bash oneos/build-oneos.sh

Ideal for developers who want Git and TLS tooling already installed.

Operate & maintain

Keep your WSL instances healthy.

Update packages regularly, rebuild when needed, and track any customizations you add after import.

Task Command
Update packages sudo apt update && sudo apt upgrade
Install a package sudo apt install <package>
Rebuild from source sudo bash oneos/build-oneos.sh then re-import
Change mirrors Set ONEOS_MIRROR and rebuild for faster updates.

Document your additions so you can replay them after rebuilding.

FAQ

Answers to common questions.

Why build instead of downloading a pre-made image?

Building keeps the image transparent and reproducible. You choose mirrors, packages, and release, then verify with checksums before sharing.

Which hosts are supported for building?

Use Debian or Ubuntu hosts with debootstrap available. Other distributions can work if debootstrap is installed and configured.

How do I update an existing OneOS instance?

Inside WSL, run sudo apt update && sudo apt upgrade. For a fresh base, rebuild the tarball and re-import.

Can I add a desktop environment?

OneOS targets terminal-centric workflows. You can install GUI components after import, but the base image stays minimal to keep WSL fast.
