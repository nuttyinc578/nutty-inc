Minimal. Root-based. Built for WSL.

OneOS keeps Windows Subsystem for Linux lean and predictable.

Quick start (Debian/Ubuntu host)

Build the rootfs locally and import it into WSL.

sudo apt update && sudo apt install -y debootstrap xz-utils
sudo bash oneos/build-oneos.sh

# Import into WSL (PowerShell)
wsl --import OneOS $env:USERPROFILE\OneOS oneos.tar.gz --version 2
wsl -d OneOS

Use env vars like ONEOS_RELEASE and ONEOS_PACKAGES to change the base release and package set.

Get OneOS

Build locally, then import into WSL.

Run the build script on a Debian/Ubuntu host, then use the generated tarball with wsl --import on Windows.

1

Prepare your host

Install debootstrap and xz-utils. The script will pull everything else it needs.

2

Build

Run sudo bash oneos/build-oneos.sh (or fetch with curl -fsSL ... | sudo bash). Customize with environment variables.

3

Import into WSL

In PowerShell: wsl --import OneOS $env:USERPROFILE\OneOS oneos.tar.gz --version 2, then start with wsl -d OneOS.

4

Stay updated

Run sudo apt update && sudo apt upgrade inside WSL. Rebuild and re-import anytime for a fresh base.

Common customization flags

Set environment variables before running the script.

ONEOS_RELEASE=bookworm \
ONEOS_MIRROR=https://deb.debian.org/debian \
ONEOS_PACKAGES="curl ca-certificates git" \
ONEOS_TARBALL=oneos-wsl.tar.gz \
sudo bash oneos/build-oneos.sh

See oneos/README.md for all available variables and defaults.

Make it yours

Choose the release, mirror, and package set.

Use environment variables to fit OneOS to your region, package needs, or team standards.

  • Release: ONEOS_RELEASE
  • Mirror: ONEOS_MIRROR
  • Packages: ONEOS_PACKAGES
  • Tarball name: ONEOS_TARBALL
Tip: Keep a tiny shell script or CI job that sets your preferred mirrors and packages so you can rebuild and re-import identically across machines.
Import cheat sheet
Step Command
Import wsl --import OneOS C:\\OneOS oneos.tar.gz --version 2

Update packages sudo apt update && sudo apt upgrade
Rebuild later sudo bash oneos/build-oneos.sh
