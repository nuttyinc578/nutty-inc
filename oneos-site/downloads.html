Downloads

Build a clean OneOS tarball, then import to WSL.

Everything you need to assemble, verify, and import OneOS. Choose the path that fits your workflow: run the script locally, or pipe it via curl.

Quick commands Releases
Standard build (recommended)
sudo apt update && sudo apt install -y debootstrap xz-utils
sudo bash oneos/build-oneos.sh

# Import on Windows (PowerShell)
wsl --import OneOS  oneos.tar.gz --version 2
# e.g., $env:USERPROFILE\OneOS or C:\\OneOS
wsl -d OneOS

Set variables like ONEOS_RELEASE, ONEOS_MIRROR, or ONEOS_PACKAGES before running to customize.

Pick your path

Run locally or fetch via curl.

Use the local script for trusted builds, or pipe over HTTPS when you need a quick bootstrap.

Local script

Keeps everything on your machine.

sudo apt install -y debootstrap xz-utils
sudo bash oneos/build-oneos.sh

Outputs oneos.tar.gz in the repo root.

Curl + bash

Great for cloud or automation runners.

curl -fsSL https://raw.githubusercontent.com/nutty-inc/oneos/main/oneos/build-oneos.sh \
 | sudo bash

Respects env vars such as ONEOS_RELEASE, ONEOS_MIRROR, and ONEOS_PACKAGES.

Customize

Add packages or change mirrors.

ONEOS_RELEASE=bookworm \
ONEOS_PACKAGES="git curl ca-certificates" \
ONEOS_TARBALL=oneos-bookworm.tar.gz \
sudo bash oneos/build-oneos.sh

Keep the tarball on a Windows path (e.g., C:\\OneOS) before importing.

Verify & share

Integrity checks for your exports.

Generate checksums before sharing tarballs with teammates. Keep your exports in a safe Windows path to avoid WSL-specific path issues.

Checksum locally
sha256sum oneos.tar.gz > oneos.tar.gz.sha256
cat oneos.tar.gz.sha256

Store the checksum alongside the archive you distribute.

Import reminders

  • Pick an install directory like C:\\OneOS or $env:USERPROFILE\\OneOS when running wsl --import.
  • Avoid importing directly from \\wsl$ shares.
  • Rebuild periodically and re-import for fresh bases.
If you automate builds, publish checksums and the exact env vars you used so others can reproduce the export.

After import

Keep your WSL instance healthy.

Once OneOS is imported, keep it patched and rebuild occasionally to refresh the base image.

Action Command
Update packages sudo apt update && sudo apt upgrade
Install extras sudo apt install <pkg> or rebuild with ONEOS_PACKAGES
Rebuild base sudo bash oneos/build-oneos.sh then re-import

Document any extra packages you add so you can replicate them during the next rebuild.
